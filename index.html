MatterRemembersIts Shape

A GPU particle field that dissolves and re-forms between geometries. Every point carries its own noise seed, curl-drift and easing curve — solved entirely in a vertex shader. Drag to orbit. Pick a form below.

No meshes.
Only points.

Target positions for each form are baked into buffer attributes once, at load. The morph is a single uniform sweeping 0→1 while curl noise pushes points off their geodesic so the transition billows instead of sliding. Nothing touches the CPU per frame.

Additive light,
not lit surfaces.

Each point renders as a soft radial sprite in additive blend, so density becomes luminance — thin regions read as haze, folds read as hot cores. Colour is a function of radial velocity, so the field flushes cyan as it collapses and cools to violet as it settles.

Built in one file.

Single HTML document. three.js, custom GLSL, zero build step, zero dependencies beyond the renderer. View source — the whole thing is right there.
